# ru-hunspell-augment

Расширение Hunspell словаря `ru_RU` дополнительными правилами словоизменения.

## Проблема

Оригинальный `ru_RU.dic` от LibreOffice содержит ~150k лемм, но многие словоформы не генерируются из-за неполноты правил в `ru_RU.aff`. Например:

- `условие` → `условием` ❌ (нет в оригинале)
- `имущество` → `имуществом` ❌
- `пункт` → `пунктам` ❌

В этом репозитории мы проанализировали 1.5 млн русских слов с помощью pymorphy2, сверили с существующими Hunspell-формами и сгенерировали **1367 дополнительных групп SFX правил**, покрывающих все недостающие формы.

## Состав

| Файл | Описание |
|---|---|
| `ru_RU.aff` | Оригинальный .aff от LibreOffice |
| `ru_RU.dic` | Оригинальный .dic от LibreOffice |
| `ru_RU_ext.aff` | Сгенерированные дополнительные правила |
| `ru_RU_full.aff` | Объединённый .aff (оригинал + дополнения) |
| `ru_RU_full.dic` | Оригинальный .dic (тот же, что и ru_RU.dic) |
| `learn_rules.py` | Скрипт для генерации правил из пар форма→лемма |

## Использование

Подключите объединённый словарь к любому Hunspell-совместимому инструменту:

```bash
# gospell (Go)
gs, _ := gospell.Open("ru_RU_full", gospell.SearchPaths())

# или hunspell CLI
hunspell -d ru_RU_full
```

## Как это работает

1. Загружается список всех словоформ из дампа русского языка (1.5M слов)
2. Для каждого слова pymorphy2 определяет лемму
3. Сверяется с формами, которые генерирует оригинальный Hunspell
4. Для недостающих пар `форма→лемма` извлекается шаблон: `lemma → strip + add + cond`
5. Шаблоны группируются по `(strip, add)`, каждой группе назначается числовой флаг (1000+)
6. Группируется по cond (последний символ перед strip)
7. Отсеиваются редкие шаблоны (< 5 лемм)

## Генерация своих правил

Запустить скрипт:

```bash
python3 learn_rules.py forms.tsv rules.aff
```

Где `forms.tsv` — TSV-файл с колонками `form` и `lemma`.
